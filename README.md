# Packet Sniffer

A Python-based cybersecurity project that captures and analyzes live network traffic using Scapy.  
This tool monitors TCP, UDP, ICMP, DNS, HTTP, and ARP packets in real time and logs packet information for analysis.

---

# Features

- Live packet sniffing
- TCP packet monitoring
- UDP packet monitoring
- ICMP packet monitoring
- DNS query detection
- HTTP packet inspection
- ARP monitoring
- Real-time packet logging
- Colored terminal output
- Packet counter

---

# Technologies Used

- Python 3
- Scapy
- Colorama
